# Kaggle notebooks

Use Kaggle notebooks to access competition inputs and GPU accelerators. The validation baseline notebook clones the public repository at main, records the resolved Git commit, and imports the shared implementation from src/.

Attach the competition dataset in Kaggle and enable internet for the repository clone and dependency check. The baseline itself is CPU-based and does not require a GPU; use a GPU accelerator for later model experiments. Record the Kaggle notebook version, source commit, accelerator, dependency versions, split digest, and output checksums in the experiment log. Do not commit downloaded data, model weights, credentials, or generated submission files.

`kaggle/public_unet_fold_aware/` runs `scripts/evaluate_public_unet_fold_aware.py` on the Kaggle GPU with the competition training data and public `dariushafshar/solar-filament-unet-weights` dataset attached. It uses only the two source-fold checkpoints that held each validation observation out, recreates the fixed split, and records the resolved Git commit and scorer metadata. The model weights are CC BY-NC-SA 4.0; retain their attribution and ShareAlike terms.

`kaggle/rfdetr_fixedholdout/` runs `scripts/evaluate_rfdetr_fixedholdout.py` on a Kaggle T4 or local CUDA GPU. It pins RF-DETR 1.8.3 and its Lightning, TorchMetrics, Transformers, and evaluator dependencies. The runner trains RF-DETR-Seg Small from the public COCO checkpoint using only the 565-observation training partition, selects the confidence threshold on an inner observation-grouped validation split with the official PQ scorer, then scores the frozen 142-observation holdout once. It writes the split digest, pretrained and fine-tuned checkpoint hashes, metrics, timing, and hardware metadata under `/kaggle/working/` or local `artifacts/`. Model and framework caches stay in workspace-local cache folders. RF-DETR-Seg and its package are Apache-2.0.

`kaggle/i079_topology_safe_refiner/` provides a private offline runner for the public I079 Mask R-CNN plus crop-refiner submission using the attached Kaggle competition input and Apache-2.0 model. The model page documents training on competition training images and annotations only; the offline inference notebook reads no training annotations or test labels. It checks both checkpoint MD5s and the exact 1,299-row submission MD5, then writes a run report and submission to `/kaggle/working/`.

`scripts/experiments/build_rule_compliant_test_consensus.py` builds a label-free test-time consensus from hash-locked candidate CSVs. Its current batch uses three distinct model families, records all input hashes, checks 2048x2048 RLE round trips and disjointness, and reads only supplied test image filenames for coverage.
